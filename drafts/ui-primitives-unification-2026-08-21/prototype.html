06

Loading shell

Some pages jump to a Not found state while data is still loading. That is the bug: "not arrived yet" is being treated as "does not exist". The fix is a shell whose shape matches the final content, built on the Skeleton shimmer. Admin insights already does this well.

shell to content, 1.4s
Right: shell matches final shape
Wrong: today on some pages
${ghost}
Nothing here
Page renders "not found" before the data even arrives.

Rule for the rollout: every page gets a shell whose skeleton mirrors its real layout, and the not-found state only shows after loading resolves to empty.

09

Modal

Used everywhere and hand-rolled in ~11 places. The best one is the explore event-detail sheet, so that becomes the primitive: a routed page shown in a sheet. Bottom sheet with drag-dismiss on mobile, centered spring-in dialog on desktop, one hero + sticky header + scrolling body + sticky footer CTA. Open it, then resize the window to see both forms.

Event-detail sheet primitivebackdrop, back and Escape all close itRecommended
